# Закупки: учёт закупок байера (веб-версия для iPhone)

Закупки на Pinduoduo для многих клиентов: клиенты, товары с ценами в юанях, курс CNY/BYN с округлением,
порядок оформления с границами между клиентами, опись без имён и треков (PDF, Excel), история закупок.
«Забрать из PDD»: разбор файла PDD.txt, который копит «Команда» iPhone по Кнопке действия (снимок экрана → текст),
товары по клиентам по времени нажатия, треки к товарам по номеру заказа.
Работает без интернета, данные хранятся только в телефоне (резервная копия — файлом).

- `site/` — само приложение без сборки (HTML, CSS, модули JS). Его и выкладываем.
- `site/vendor/` — библиотеки: Preact+htm, idb, pdfmake 0.2.23 (Roboto с кириллицей), SheetJS 0.20.3. Копирует `npm run vendor`.
- `tests/` — автотесты денег, курса, округления, описи, границ клиентов, дублей, экспорта: `npm test`.
- `npm run serve` — открыть на компьютере: http://localhost:5181.
- `scripts/icons.mjs` — рисует значки.
- `.github/workflows/pages.yml` — после отправки в `main`: тесты и выкладка на GitHub Pages.

Главные файлы: `src/pddimport.js` (разбор снимков PDD), `src/money.js` (деньги в фэнях и копейках), `src/opis.js` (опись и объединение),
`src/order.js` (порядок оформления), `src/model.js` (статусы, проверки, дубли), `src/store.js` (данные и журнал),
`src/db.js` (IndexedDB), `src/export.js` (PDF и Excel), `src/screens/*` (экраны), `sw.js` (без интернета).
